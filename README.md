# Operating-Platforms

•	Briefly summarize The Gaming Room client and their software requirements. Who was the client? What type of software did they want you to design?
The Gaming Room client wants to create a software for other devices for their video game to reach a greater audience. 

•	What did you do particularly well in developing this documentation?
For the project gathering information about the different devices for our software project. I was able to compare the best device for the Gaming Room software. This also gave me the chance to learn a bit about software engineering before coding begins i.e., Software design.

•	What about the process of working through a design document did you find helpful when developing the code?
The process of creating UML charts helped me through developing the code by providing different types of charts from visualization of how the program works and providing a step-by-step list.

•	If you could choose one part of your work on these documents to revise, what would you pick? How would you improve it?
I choose to revise my first draft of The Gaming Room software design; I could have elaborated on my ideas for the software more and created a better streamline program. I would have improved on design constraints and requirements for the gaming room.

•	How did you interpret the user’s needs and implement them into your software design? Why is it so important to consider the user’s needs when designing?
As a gamer, I was able to use my experience playing videogames to devise ideas to implement into the program. Such as having a multi-player system built-in for some players to play with friends online or family.

•	How did you approach designing software? What techniques or strategies would you use in the future to analyze and design a similar software application?
I approached designing software by relaying on the client’s thoughts and feelings on the software and using my own knowledge to give an outside opinion on what the program could be.
